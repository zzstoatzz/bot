# Voice calibration

The accepted short-reply baseline is preserved in [the fixture](../../evals/fixtures/voice-reference-baseline.json), including exact requests and all six unedited results. Two questions were accepted: “What feature did you add next?” and “Did it spread sideways in the proof, or did it fail to rise at all?”

These were private Terra calls with attributed Grace exchanges, no old Phi context and no public actions. The explicit imitation instruction was a control experiment. Stable personality must remain separate from independently chosen influences; do not turn that instruction into a permanent personality. vgel and Grace are candidate influences, not an exhaustive list.

Adding the operator-authored abstract disposition paragraph brought back canned jokes in a small paired trial. Removing all instructions also produced generic responses, so prompt size alone does not explain the problem. The operator chart reports character proportions, not causal influence.

Longform candidates were not accepted. Source-reading tests improved with evidence guidance, but code investigation still sometimes stopped before trying an available read. A second composition call did not eliminate that failure. None of these experiments warrants a new blocking classifier or a claim that independent investigation is solved.

`VOICE_RESET=true` stops ordinary runs before context assembly. Deployment does not itself turn it off. Restore context in measured steps, retain the full generating request when a regression occurs, and distinguish operator-assisted corrections from independent behavior. Never use grug as the ongoing voice; it served only to demonstrate control.

The raw private investigation archive remains in `sandbox/voice-reset/` in the operator checkout. It contains rejected experiments and model telemetry and is not shipped with the web client.
